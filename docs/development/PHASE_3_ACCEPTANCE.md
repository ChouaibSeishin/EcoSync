Known limits: bearer-only controlled Streamable HTTP and tested Tools for 2025-11-25/2026-07-28; bounded JSON Schema subset; no OAuth/STDIO/resources/prompts/tasks/roots/sampling/elicitation UI; single backend replica, in-memory HTTP sessions/throttling; no automatic tool-call retry; development HTTP and Vite server; external-key backup/rotation are operator responsibilities. Native demos do not advertise output schemas, so declared-output validation is exercised with official peers rather than invented source schemas. The additional Node process/hop has not been benchmarked. The exact temporary minimatch 11.0.1 security override is outside the original lint dependency major range; repo lint file coverage/types/build/tests/audit passed, and it must be revisited when upstream packages adopt the fixed version. Point-in-time audits are not an exhaustive security assessment.

The 30-second budget applies to each client connection/discovery/invocation operation; cold API recovery can involve multiple such bounded stages. Remote tool cancellation is best effort and cannot undo a completed read. Java compiled and PostgreSQL tests ran natively on Windows; actual Java MCP wire/runtime acceptance uses the pinned Linux containers after the host Windows proof hit an NIO selector error before communication. Local startup/verification creates no paid-provider dependency.
